# Calisthenics Coach

Aplicativo de calistenia para Android, offline e sem conta.

## Baixar a versão atual (1.7.0)

**[Toque aqui para baixar o instalador (APK)](https://github.com/clethosgtr/calisthenics-coach-releases/raw/main/apk/CalisthenicsCoach-1.7.0.apk)**

### Como instalar
1. Toque no link acima pelo celular Android e baixe o arquivo.
2. Abra o arquivo baixado. Se o Android pedir, permita a instalação de apps desta origem (navegador ou gerenciador de arquivos).
3. Toque em **Instalar**.

Depois de instalado, as próximas atualizações são feitas dentro do app, em **Perfil → Atualizações**, sem perder seus dados.
