# Calisthenics Coach

Aplicativo de calistenia, sem conta e com os dados guardados só no seu aparelho. Versão atual: **1.12.1**

## Android
**[Baixar o instalador (APK)](https://github.com/clethosgtr/calisthenics-coach-releases/raw/main/apk/CalisthenicsCoach-1.12.1.apk)**

1. Toque no link pelo celular Android e baixe o arquivo.
2. Abra o arquivo baixado. Se o Android pedir, permita a instalação de apps desta origem.
3. Toque em **Instalar**.

As próximas atualizações são feitas dentro do app, em **Perfil → Atualizações**, sem perder seus dados.

## iPhone e computador (navegador)
**[Abrir o app no navegador](https://clethosgtr.github.io/calisthenics-coach-releases/)**

No iPhone: abra o link no **Safari**, toque no botão de compartilhar e escolha **Adicionar à Tela de Início**. Use sempre o ícone criado (o Safari e o ícone guardam dados separados).
A versão para navegador se atualiza sozinha: basta fechar e abrir o app de novo.
